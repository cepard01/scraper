# Brique M0–M4 — Ingestão, normalização, valoração, score e pipeline

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** entregar o pipeline que varre OLX e Mercado Livre, normaliza anúncios em produtos canônicos, estima valor de revenda, calcula margem e ranqueia oportunidades num terminal — sem IA e sem painel.

**Architecture:** monorepo pnpm com três pacotes. `@brique/core` contém domínio, banco e toda a matemática (e **nunca** acessa marketplace); `@brique/scrapers` contém um `SourceAdapter` por fonte, que é o único lugar que conhece a estrutura de cada site; `@brique/worker` agenda e executa o pipeline. O banco (SQLite/WAL) é o único ponto de integração, preparado para virar Postgres atrás dos repositórios.

**Tech Stack:** Node 24, TypeScript 6.0.3 (ESM, `moduleResolution: bundler`), pnpm 11, vitest 5.0.5, tsx 4.23.15, Drizzle ORM 0.45.4 + drizzle-kit 0.31.11, better-sqlite3 13.0.3, zod 4.6.7.

**Spec:** [`docs/superpowers/specs/2026-10-31-brique-vertical-design.md`](../specs/2026-10-31-brique-vertical-design.md) — lê-se junto com este plano; as seções §nn citadas aqui apontam para ela.

**Este plano cobre M0–M4.** M5 (IA/OmniRoute), M6 (painel Next), M7 (ntfy) e M8 (P&L) recebem plano próprio. Ao fim daqui, os critérios de aceite §16.1–16.3 da spec já são verificáveis, exceto os que dependem de tela.

**Desvios declarados da spec (não são liberdade criativa):**

1. §3 diz "datas armazenadas em ISO UTC". Aqui são armazenadas como `integer` epoch ms UTC (`timestamp_ms` do Drizzle). O invariante que importa — nunca horário local, sempre UTC, exibição em `America/Sao_Paulo` — permanece; `Date` na borda do repositório, formatação só na apresentação. Registrado na spec em §3.1 ao fim da Task 3.
2. §9 (`dealAlert`) e §7 (camada de IA) não têm task aqui. A pipeline termina escrevendo `opportunity` com `status` de finalista e imprimindo a fila no terminal. A costura existe: `AiTriagePort` injetado, com implementação `nullAiPort` que contabiliza chamadas — e os testes **exigem** que ela nunca seja chamada para item `unchanged` (que é exatamente o aceite §16.2, já verificável agora).

## Global Constraints

Vale para toda task. Valores copiados verbatim da spec.

- Node `>=22.22.2 <23` **ou** `>=24 <27`; Node 23 é excluído (piso do OmniRoute, que precisará disso na M5). Esta máquina: v24.
- TypeScript estrito: `strict: true`, `noUncheckedIndexedAccess: true`, `exactOptionalPropertyTypes: false`.
- ESM puro (`"type": "module"`), `moduleResolution: "bundler"`, `module: "ESNext"`; nunca `emit`, `tsx` roda o TS direto.
- **Dinheiro é inteiro em centavos** (`type Cents = number`, campos suffixados `Cents`). Nunca float, nunca `toFixed` em conta intermediária. Moeda BRL.
- Nomes de coluna e de campo em `camelCase`; nomes de tabela SQL em `snake_case`.
- Datas: epoch ms UTC no banco; `Date` nos repositórios; exibição `America/Sao_Paulo`.
- **`@brique/core` não faz rede com marketplace.** Só recebe `RawListing`/`ListingInput` já baixados. Teste de core não pode ter `fetch`.
- **Nenhuma requisição de rede em teste automatizado.** Rede viva é comando manual explícito (`pnpm smoke:olx`, `pnpm smoke:meli`).
- Regra de dependência (violação = task rejeitada): `scrapers → core`, `worker → scrapers + core`, `core → nada interno`.
- Toda fórmula de margem/lucro vive em `core`; SQL dos repositórios só agrega linhas já calculadas (§3.1).
- Preços-piso default desta fase, todos lidos de `settings` (§6.2) e gravados em `DEFAULT_SETTINGS` com estes nomes exatos: `floorMarginPct = 0.35`, `floorMarginCents = 6000` (R$ 60,00), `delta = 0.85`, `metaPerDayCents = 4000` (R$ 40,00/dia), `metaDays = 14`, `metaStaleDays = 30`, `weights = { profit: 0.45, liquidity: 0.25, confidence: 0.15, freshness: 0.15 }`.
- `pnpm` é o gerenciador. O pnpm 11 **bloqueia scripts de build por padrão** — `better-sqlite3` e `esbuild` precisam de allowlist explícita ou o binário nativo fica ausente. Em pnpm 11 a allowlist mora em `pnpm-workspace.yaml` com a chave `allowBuilds` (mapa `pacote: true`); o campo `pnpm.onlyBuiltDependencies` em `package.json` não é mais lido, e a lista `onlyBuiltDependencies:` no yaml tampouco autoriza build (verificado em pnpm 11.20: ambas dão `ERR_PNPM_IGNORED_BUILDS`).
- Commit ao fim de cada task, com todos os testes daquela task verdes (`pnpm typecheck && pnpm test`).
- Filtro de teste é `pnpm exec vitest run <nome>` — `pnpm test -- <nome>` **não** filtra nesta combinação pnpm 11 + vitest 5 (o `--` vira argumento posicional e a suíte inteira roda; verificado na Task 2).

O campo `exports` com o padrão `./*": "./src/*.ts"` é o que faz `@brique/core/money` resolver para `packages/core/src/money.ts` **em runtime**. Não é detalhe de estilo: `tsx` e o resolvedor do Vite/Vitest seguem o mapa de `exports` do pacote, e os `paths` do `tsconfig` só orientam o `tsc` (o Vitest os ignora a menos que se instale `vite-tsconfig-paths`, que aqui não entra). Ou seja, `exports` resolve, `paths` satisfaz o typecheck — os dois são necessários, e só o `exports` precisa conter a extensão `.ts` no alvo. Um import `@brique/core/db/repo/listings` cai em `src/db/repo/listings.ts` com a mesma regra, então não há mapa para manter em dia quando um arquivo novo nasce.

```ts
import { z } from 'zod';

export class ConfigError extends Error {
  override readonly name = 'ConfigError';
}

const EnvSchema = z.object({
  DATABASE_URL: z.string().min(1),
  OMNIROUTE_BASE_URL: z.string().default('http://127.0.0.1:20128/v1'),
  OMNIROUTE_API_KEY: z.string().optional(),
  MELI_ACCESS_TOKEN: z.string().optional(),
  MELI_UNIT: z.string().default('MLB'),
  NTFY_BASE_URL: z.string().default('https://ntfy.sh'),
  NTFY_TOPIC: z.string().optional(),
  WEB_PORT: z.coerce.number().int().min(1).max(65535).default(3000),
  TZ_DISPLAY: z.string().default('America/Sao_Paulo'),
});

export interface Config {
  databaseUrl: string;
  sqlitePath: string;
  meliToken: string | null;
  meliUnit: string;
  omniRoute: { baseUrl: string; apiKey: string | null };
  ntfy: { baseUrl: string; topic: string | null };
  webPort: number;
  tz: string;
}

// emptyToNull e blankToUndefined cobrem bordas diferentes: o primeiro é o contrato de
// segredo (ausente ou vazio => null, e os consumidores decidem se isso desliga a fonte);
// o segundo existe só para o .default() do zod ver undefined. Nenhum substitui o outro.
const emptyToNull = (v: string | undefined): string | null => (v && v.length > 0 ? v : null);

// `MELI_UNIT=` vazio no .env chega como '', e zod só aplica .default() em undefined.
const blankToUndefined = (env: NodeJS.ProcessEnv): Record<string, string | undefined> =>
  Object.fromEntries(Object.entries(env).map(([k, v]) => [k, v === '' ? undefined : v]));

export function parseSqlitePath(databaseUrl: string): string {
  if (!databaseUrl.startsWith('sqlite://')) {
    const scheme = /^([a-z][a-z0-9+.-]*):\/\//i.exec(databaseUrl)?.[1] ?? 'sem esquema';
    throw new ConfigError(`DATABASE_URL precisa começar com sqlite:// nesta fase (esquema recebido: "${scheme}"). Postgres chega na migração para VPS.`);
  }
  const path = databaseUrl.slice('sqlite://'.length);
  if (path.length === 0) {
    throw new ConfigError('DATABASE_URL precisa de um caminho depois de sqlite:// (ex.: sqlite://./data/brique.db).');
  }
  return path;
}

export function loadConfig(env: NodeJS.ProcessEnv = process.env): Config {
  const parsed = EnvSchema.safeParse(blankToUndefined(env));
  if (!parsed.success) {
    const names = parsed.error.issues.map((i) => (i.path[0] ?? '?') as string).join(', ');
    throw new ConfigError(`config inválida, faltam/erradas: ${names}`);
  }
  const e = parsed.data;
  return {
    databaseUrl: e.DATABASE_URL,
    sqlitePath: parseSqlitePath(e.DATABASE_URL),
    meliToken: emptyToNull(e.MELI_ACCESS_TOKEN),
    meliUnit: e.MELI_UNIT,
    omniRoute: { baseUrl: e.OMNIROUTE_BASE_URL, apiKey: emptyToNull(e.OMNIROUTE_API_KEY) },
    ntfy: { baseUrl: e.NTFY_BASE_URL, topic: emptyToNull(e.NTFY_TOPIC) },
    webPort: e.WEB_PORT,
    tz: e.TZ_DISPLAY,
  };
}
```

```ts
import { mkdirSync } from 'node:fs';
import { dirname } from 'node:path';
import Database from 'better-sqlite3';
import { drizzle, type BetterSQLite3Database } from 'drizzle-orm/better-sqlite3';
import { migrate } from 'drizzle-orm/better-sqlite3/migrator';
import * as schema from './schema';

export type Db = BetterSQLite3Database<typeof schema>;

export interface DbHandle { sqlite: Database.Database; db: Db }

export function openDb(path: string): DbHandle {
  if (path !== ':memory:') mkdirSync(dirname(path), { recursive: true });
  const sqlite = new Database(path);
  sqlite.pragma('journal_mode = WAL');
  sqlite.pragma('busy_timeout = 5000');
  sqlite.pragma('foreign_keys = ON');
  return { sqlite, db: drizzle(sqlite, { schema }) };
}

export function migrateDb(db: Db, folder = './drizzle'): void {
  migrate(db, { migrationsFolder: folder });
}
```

export function upsertFromSource(db: Db, input: ListingInput, opts: UpsertOpts): UpsertResult {
  const existing = db.select().from(listings)
    .where(and(eq(listings.source, input.source), eq(listings.externalId, input.externalId)))
    .get();

  if (!existing) {
    const inserted = db.insert(listings).values({
      source: input.source,
      externalId: input.externalId,
      url: input.url,
      monitorId: opts.monitorId ?? null,
      fingerprintId: opts.fingerprintId ?? null,

      title: input.title,

      city: input.city,

      sellerRef: input.sellerRef,
      publishedAt: input.publishedAt,
      firstSeenAt: opts.seenAt,
      lastSeenAt: opts.seenAt,
      rawPayload: input as unknown,
      parserVersion: opts.parserVersion,
    }).returning({ id: listings.id }).get();
    const id = inserted.id;
    db.insert(pricePoints).values({ listingId: id, askingCents: input.askingCents, observedAt: opts.seenAt }).run();
    return { id, transition: 'new' };
  }

  const priceChanged = existing.askingCents !== input.askingCents;
  const wasGone = existing.status === 'gone';
  db.update(listings).set({
    url: input.url,
    title: input.title,
    description: input.description,
    askingCents: input.askingCents,
    askingRaw: input.askingRaw,
    city: input.city ?? existing.city,
    uf: input.uf ?? existing.uf,
    imageUrls: input.imageUrls.length > 0 ? input.imageUrls : existing.imageUrls,
    sellerRef: input.sellerRef ?? existing.sellerRef,
    publishedAt: input.publishedAt ?? existing.publishedAt,
    lastSeenAt: opts.seenAt,
    status: (priceChanged || wasGone ? 'repriced' : 'unchanged') as ListingStatus,
    monitorId: opts.monitorId ?? existing.monitorId,
    fingerprintId: opts.fingerprintId ?? existing.fingerprintId,
    grade: opts.grade ?? existing.grade,
  }).where(eq(listings.id, existing.id)).run();

  if (priceChanged) {
    db.insert(pricePoints).values({ listingId: existing.id, askingCents: input.askingCents, observedAt: opts.seenAt }).run();
    return { id: existing.id, transition: 'repriced' };
  }
  return { id: existing.id, transition: 'unchanged' };
}

export function markGone(db: Db, source: SourceId, seenExternalIds: string[], now: Date): number {
  const active = db.select({ externalId: listings.externalId, id: listings.id })
    .from(listings)
    .where(and(eq(listings.source, source), ne(listings.status, 'gone'), ne(listings.status, 'bought')))
    .all();
  const seen = new Set(seenExternalIds);
  const missing = active.filter((r) => !seen.has(r.externalId));
  for (const r of missing) {
    db.update(listings).set({ status: 'gone', lastSeenAt: now }).where(eq(listings.id, r.id)).run();
  }
  return missing.length;
}

export interface ComparableRow {
  listingId: number;
  askingCents: number;
}

export function findComparables(
  db: Db,
  fingerprintId: number,
  opts: { windowDays: number; variantAgnostic: boolean; now: Date; excludeListingId?: number },
): ComparableRow[] {
  const since = new Date(opts.now.getTime() - opts.windowDays * 86_400_000);
  const cols = db.select({ listing: listings, fp: fingerprints })
    .from(listings)
    .innerJoin(fingerprints, eq(fingerprints.id, listings.fingerprintId))
    .where(and(gte(listings.lastSeenAt, since), isNull(listings.dupeOf)))
    .all();

  const anchor = cols.find((c) => c.fp.id === fingerprintId)?.fp;
  if (!anchor) return [];

  const matched = cols.filter((c) => {
    if (c.fp.id === fingerprintId) return true;
    if (!opts.variantAgnostic) return false;
    return c.fp.category === anchor.category && c.fp.brand === anchor.brand && c.fp.model === anchor.model;
  });

  return matched
    .filter((c) => c.listing.status !== 'bought')
    .filter((c) => c.listing.id !== opts.excludeListingId)
    .map((c) => ({ listingId: c.listing.id, askingCents: c.listing.askingCents }));
}

export function attachDupe(db: Db, listingId: number, dupeOfId: number): void {
  db.update(listings).set({ dupeOf: dupeOfId }).where(eq(listings.id, listingId)).run();
}

import { eq } from 'drizzle-orm';
import type { Db } from '../client';
import { fingerprints } from '../schema';
import type { ParsedProduct } from '../../types';

export function fingerprintKey(p: ParsedProduct): string {
  return [p.category, p.brand ?? '?', p.model ?? '?', p.variant ?? '?', p.grade].join('|');
}

const ACRONYMS: Record<string, string> = {
  iphone: 'iPhone', ipad: 'iPad', ipod: 'iPod', imac: 'iMac',
  ps3: 'PS3', ps4: 'PS4', ps5: 'PS5', xbox: 'Xbox', nintendo: 'Nintendo',
  tv: 'TV', led: 'LED', lcd: 'LCD', oled: 'OLED', amoled: 'AMOLED',
  mtb: 'MTB', aro: 'Aro', gta: 'GTA', fifa: 'FIFA',
};

function labelToken(token: string): string {
  const lower = token.toLowerCase();
  const acronym = ACRONYMS[lower];
  if (acronym) return acronym;
  const unit = /^(\d+)(gb|tb|mb)$/.exec(lower);
  if (unit?.[1] && unit[2]) return unit[1] + unit[2].toUpperCase();
  return lower.charAt(0).toUpperCase() + lower.slice(1);
}

export function fingerprintLabel(p: ParsedProduct): string {
  const tokens = `${p.model ?? p.category} ${p.variant ?? ''}`
    .split(/[\s-]+/)
    .map(labelToken)
    .filter((t) => t.length > 0);
  return `${tokens.join(' ')} (${p.grade})`;
}

export function getOrCreateFingerprint(db: Db, p: ParsedProduct): { id: number; key: string; label: string } {
  const key = fingerprintKey(p);
  const existing = db.select().from(fingerprints).where(eq(fingerprints.key, key)).get();
  if (existing) return { id: existing.id, key: existing.key, label: existing.label };
  return db.insert(fingerprints)
    .values({ key, category: p.category, brand: p.brand, model: p.model, variant: p.variant, grade: p.grade, label: fingerprintLabel(p) })
    .returning({ id: fingerprints.id, key: fingerprints.key, label: fingerprints.label })
    .get();
}
```

`fingerprintLabel` usa um mapa de siglas em vez de um `replace(/\b\w/g, c => c.toUpperCase())` porque o título brasileiro de eletrônico é uma mistura de case-sensitive: `iphone 12` tem de virar `iPhone 12`, `128gb` tem de virar `128GB` e `ps4 slim` tem de virar `PS4 Slim`. O title-case ingênuo produz `Iphone 12 128Gb` e `Ps4 Slim`, que é o tipo de detalhe que faz o painel parecer amador e que ninguém nota no teste de feliz caminho — por isso a regra está no código e o caso `PS4` está no teste abaixo, não como comentário.

```ts
import type { Cents } from './types';

export type PriceReject =
  | 'empty' | 'not-a-price' | 'zero' | 'gratuito' | 'troco' | 'a-combinar' | 'negativo' | 'absurdo';

export type PriceResult = { ok: true; cents: Cents } | { ok: false; reason: PriceReject };

const REJECT_PREFIX: Array<[string, PriceReject]> = [
  ['gratis', 'gratuito'], ['free', 'gratuito'],
  ['troco', 'troco'], ['troca', 'troco'], ['troco por', 'troco'],
  ['a combinar', 'a-combinar'], ['combinar', 'a-combinar'], ['sob consulta', 'a-combinar'],
  ['consultar', 'a-combinar'],
];

const DEFAULT_MAX_CENTS = 200_000_000;

export function parsePriceBRL(input: string, opts: { maxCents?: Cents } = {}): PriceResult {
  const max = opts.maxCents ?? DEFAULT_MAX_CENTS;
  const raw = (input ?? '').trim();
  if (!raw) return { ok: false, reason: 'empty' };

  const lowered = raw.toLowerCase().normalize('NFD').replace(/[\u0300-\u036f]/g, '');
  for (const [word, reason] of REJECT_PREFIX) {
    if (lowered === word || lowered.startsWith(`${word} `)) return { ok: false, reason };
  }
  if (lowered.startsWith('-') || /\bmenos\b/.test(lowered)) return { ok: false, reason: 'negativo' };

  const digitsOnly = lowered
    .replace(/\s/g, '')
    .replace(/[^\d.,]/g, '');
  if (!/[1-9]/.test(digitsOnly)) return digitsOnly ? { ok: false, reason: 'zero' } : { ok: false, reason: 'not-a-price' };

  const parsed = splitSeparators(digitsOnly);
  if (!parsed) return { ok: false, reason: 'not-a-price' };

  const cents = Math.round(parsed.integer * 100 + parsed.fracCents);
  if (cents === 0) return { ok: false, reason: 'zero' };
  if (cents > max) return { ok: false, reason: 'absurdo' };
  return { ok: true, cents };
}

function splitSeparators(s: string): { integer: number; fracCents: number } | null {
  if (/[^0-9.,]/.test(s)) return null;
  const seps = [...s.matchAll(/[.,]/g)];
  if (seps.length === 0) return { integer: Number(s), fracCents: 0 };

  const last = seps[seps.length - 1]!;
  const tail = s.slice(last.index + 1);
  if (!/^\d+$/.test(tail)) return null;

  const intPart = s.slice(0, last.index).replace(/[^0-9]/g, '');

  if (tail.length === 3) {
    const merged = intPart + tail;
    return { integer: Number(merged.length > 0 ? merged : '0'), fracCents: 0 };
  }
  return { integer: Number(intPart.length > 0 ? intPart : '0'), fracCents: Number(tail.padEnd(2, '0').slice(0, 2)) };
}

const BRL = new Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' });

export function formatBRL(cents: Cents): string {
  const value = cents / 100;
  if (cents < 0) return `-${BRL.format(Math.abs(value))}`;
  return BRL.format(value);
}
```

A regra dos três dígitos é a decisão de parsing mais importante deste arquivo, e ela não tem alternativa correta: `1.234` em anúncio brasileiro é milhar (R$ 1.234,00), não `1,234` reais. Só um grupo final de 1 ou 2 dígitos é decimal (`980.50`, `99.9`). Isso significa que `1.234,567` vira R$ 1.234.567 — um formato que não existe em anúncio nenhum, então o custo de errar aqui é zero e o de tentar cobri-lo seria um ramo que ninguém testa. O teto `maxCents` existe para o caso de verdade: um preço absurdamente alto é rejeitado com motivo `'absurdo'` antes de entrar em qualquer mediana.

const URGENCY = [
  'urgente', 'urgência', 'urgen', 'não fico até amanhã', 'nao fico amanha', 'vendo rápido',
  'vendo rapido', 'última chance', 'ultima chance', 'corra', 'corra antes que suma',
  'não perca', 'nao perca', 'promoção relâmpago', 'frete grátis só hoje',
];

const STOP_SYMBOLS = /[^\p{L}\p{N}\s]+/gu;

export function stripAccents(s: string): string {
  return s.normalize('NFD').replace(/[\u0300-\u036f]/g, '');
}

export function normalizeCase(s: string): string {
  return stripAccents(s.toLowerCase());
}

export function cleanTitle(s: string): string {
  let out = normalizeCase(s ?? '');
  out = out.replace(new RegExp(URGENCY.map((u) => escapeRe(normalizeCase(u))).join('|'), 'g'), ' ');
  out = out.replace(STOP_SYMBOLS, ' ');
  return out.replace(/\s+/g, ' ').trim();
}

function escapeRe(s: string): string {
  return s.replace(/[.*+?^${}()|[\]\\]/g, String.raw`\$&`);
}

export function shingles(s: string, n = 3): Set<string> {
  const tokens = cleanTitle(s).split(' ').filter(Boolean);
  const out = new Set<string>();
  if (tokens.length === 0) return out;
  if (tokens.length <= n) {
    out.add(tokens.join(' '));
    return out;
  }
  for (let i = 0; i + n <= tokens.length; i++) out.add(tokens.slice(i, i + n).join(' '));
  return out;
}

export function jaccard(a: Set<string>, b: Set<string>): number {
  if (a.size === 0 && b.size === 0) return 0;
  let inter = 0;
  for (const item of a) if (b.has(item)) inter++;
  return inter / (a.size + b.size - inter);
}

Ordem de checagem é o primeiro ponto: `D` vem antes de tudo porque "ótimo estado mas não liga" precisa virar `D`, não `B`. O segundo ponto é sutil e mata quem não o vê: o texto é comparado **sem acentos** (por `normalizeCase`), então uma lista com `'não liga'` nunca casaria com o texto normalizado `'nao liga'`. import type { Grade } from './types';
import { normalizeCase } from './text';

const D = ['não liga', 'não funciona', 'defeituoso', 'com defeito', 'defeito em', 'quebrado',
  'tela quebrada', 'tela trincada', 'não aciona', 'para peça', 'pra peça', 'serve para peça',
  'apenas peça', 'somente peça', 'não liga mais', 'sem tela', 'não carrega'];

  'acompanha nf', 'lacre', 'selado', 'na caixa lacrado'];

const C = ['marcas de uso', 'marcas na carcaça', 'marcas', 'arranhão', 'arranhado', 'detalhe',
  'descascado', 'amassado', 'bem usado', 'pouco conservado'];

const B = ['usado', 'usados', 'usada', 'seminovo', 'semi novo', 'pouco uso', 'poucos usos',
  'conservado', 'impecável', 'excelente estado', 'ótimo estado', 'bom estado', 'como novo'];

const hits = (text: string, keys: string[]): boolean => {
  const t = normalizeCase(text);
  return keys.some((k) => t.includes(normalizeCase(k)));
};

export function detectGrade(text: string): Grade {
  if (hits(text, D)) return 'D';
  if (hits(text, A)) return 'A';
  if (hits(text, C)) return 'C';
  if (hits(text, B)) return 'B';
  return 'B';
}

    if (category === 'outro') continue;
    const hits = rule.include.filter((x) => text.includes(x)).length;
    if (hits === 0) continue;
    const includeAt = firstMatch(text, rule.include);
    const excludeAt = firstMatch(text, rule.exclude);
    if (excludeAt >= 0 && excludeAt < includeAt) continue;
    const score = rule.weight + hits;
    if (score > bestScore) { bestScore = score; best = category; }

  return best;

  let idx = -1;
  for (const w of words) {
    const i = text.indexOf(w);
    if (i >= 0 && (idx === -1 || i < idx)) idx = i;
  }
  return idx;
}

O texto pesquisado é `título + descrição`, e como o título vem primeiro a posição dele domina — que é exatamente a semântica que se quer, sem precisar de parsing sintático.

Consequência prática para quem for ampliar as listas: um termo de `exclude` pode ser uma palavra solta (`'ssd'`, `'controle'`, `'capinha'`) porque só veta quando abre o título. Não troque esses termos por frases de duas palavras "por segurança" — `"Carregador de Notebook Dell 65w"` deixaria de casar com a frase `'carregador notebook'` por causa do `de` no meio e o acessório viraria notebook.

```ts
import type { Category, ParsedProduct } from './types';
import { cleanTitle, normalizeCase } from './text';
import { classifyCategory, matchBrand } from './category';
import { detectGrade } from './grade';

const CARRIERS = ['claro', 'vivo', 'tim', 'oi', 'next', 'sercomtel'] as const;

export function modelFor(text: string, category: Category, brand: string | null): string | null {
  const t = ` ${cleanTitle(text)} `;
  if (category === 'celular') {
    const m = t.match(/iphone\s*(\d{1,2}(?:\s?(?:pro|max|plus|mini|se))?)/) ?? t.match(/(galaxy|redmi|poco|note|moto|edge|zenfone)\s*([a-z]?\d{1,3}[a-z0-9]*)/);
    if (!m) return null;
    return normalizeCase(m[0].trim().replace(/\s+/g, ' '));
  }
  if (category === 'notebook') {
    const m = t.match(/(inspiron|latitude|thinkpad|ideapad|macbook|vivobook|aspire|nitro|chromebook)[\s-]*([a-z0-9]{1,8})?/);
    return m ? normalizeCase(m[0].trim()) : (brand ?? null);
  }
  if (category === 'console') {
    const m = t.match(/(playstation|ps)\s*([45])\s*(slim|pro|fat)?/);
    if (m) return `ps${m[2]}${m[3] ? ` ${m[3]}` : ''}`;
    const x = t.match(/xbox\s*(series\s*[xs]|one\s*(s|x)?)?/);
    return x ? normalizeCase(x[0].trim()) : null;
  }
  if (category === 'bicicleta') {
    const m = t.match(/(elite|caloi|snowland|hardrock|marlin|chameleon|trail|rusher|storm)[\s-]*([a-z0-9]{1,10})?/);
    return m ? normalizeCase(m[0].trim()) : null;
  }
  if (category === 'autopeca') {
    const m = t.match(/\b(gol|corsa|uno|palio|argo|strada|onix|corolla|civic|fit|saveiro|voyage|cg\s?160|factor|fan)\b/);
    return m ? normalizeCase(m[0]) : null;
  }
  return null;
}

export function variantFor(text: string, category: Category): string | null {
  const t = ` ${cleanTitle(text)} `;
  const parts: string[] = [];

  if (category === 'celular' || category === 'console') {
    const gb = t.match(/(\d{2,3})\s*gb\b/);
    if (gb?.[1]) parts.push(`${gb[1]}gb`);
    const tb = t.match(/(\d{1,2})\s*tb\b/);
    if (tb?.[1]) parts.push(`${tb[1]}tb`);
  }

  if (category === 'celular') {
    if (/\bdesbloquead\w*\b/.test(t)) parts.push('desbloqueado');
    else {
      const carrier = CARRIERS.find((c) => new RegExp(`\\b${c}\\b`).test(t));
      if (carrier) parts.push(carrier);
      else if (/\bbloquead\w*\b/.test(t)) parts.push('bloqueado');
    }
  }

  if (category === 'notebook') {
    const ram = t.match(/(\d{1,3})\s*gb\b/);
    const storage = t.match(/(\d{2,4})\s*(ssd|hdd)/);
    if (ram?.[1]) parts.push(`ram${ram[1]}gb`);
    if (storage?.[1] && storage[2]) parts.push(`${storage[2]}${storage[1]}`);
  }

  if (category === 'bicicleta') {
    const aro = t.match(/\baro\s*(\d{2})\b/);
    if (aro?.[1]) parts.push(`aro${aro[1]}`);
  }

  const conditionWord = /\blacrado\b/.test(t) ? 'lacrado' : null;
  if (conditionWord && parts.length === 0) parts.push(conditionWord);
  return parts.length > 0 ? parts.join('-') : null;
}

export function extractProduct(title: string, description: string): ParsedProduct {
  const category = classifyCategory(title, description);
  const haystack = `${title} ${description}`;
  if (category === 'outro') {
    return { category: 'outro', brand: null, model: null, variant: null, grade: detectGrade(haystack), matched: false };
  }
  const brand = matchBrand(haystack, category);
  const model = modelFor(haystack, category, brand);
  const variant = variantFor(haystack, category);
  return {
    category, brand, model, variant,
    grade: detectGrade(haystack),
    matched: brand !== null && model !== null,
  };
}
```

`matched` exige marca **e** modelo porque valoração sem as duas junta produtos diferentes sob um fingerprint só — o pior tipo de margem fantasma. Item não-matched vai para a contagem `unmatched` do `run` (Task 16), então você enxerga o quanto o parser está deixando passar.

Três escolhas dentro de `variantFor` que mudam o fingerprint e que valem a explicação antes do teste:

- **Os nomes de operadora são casados com fronteira de palavra.** `t.includes('tim')` sem `\b` casa dentro de `ótimo` → `otimo`, que aparece em milhares de títulos de celular. O item entraria na variante `tim` e passaria a ser comparado com aparelhos bloqueados — referência errada, alerta errado, e nenhum teste de feliz caminho vê. O mesmo vale para `oi`.
- **Em notebook, `gb` é memória, não armazenamento.** Um único `(\d{2,3})\s*gb` genérico pegaria o `8GB` de RAM de `Notebook Dell i5 8GB 256SSD` e ignoraria o SSD. Como a capacidade de armazenamento é o que separa preço em notebook, a categoria tem seu próprio par de capturas (`ram…` e `ssd…`/`hdd…`), e o `gb` genérico roda só para celular e console.
- **`lacrado` só entra quando não há variante real.** Misturar condição numa chave de produto criaria fingerprints paralelos para o mesmo aparelho. É um desempate pobre, e por isso é o último recurso, não o primeiro.

```ts
export interface HttpResult {
  status: number;
  text: string;
  error?: 'timeout' | 'network' | 'http';
  json: <T>() => T;
}

export type FetchLike = (url: string, init?: { headers?: Record<string, string>; signal?: AbortSignal }) => Promise<{ status: number; body: string }>;

export interface HttpOpts {
  userAgent: string;
  timeoutMs?: number;
  jitterMs?: [number, number];
  maxAttempts?: number;
  baseDelayMs?: number;
  fetchImpl?: FetchLike;
}

export type HttpGet = (url: string, init?: { headers?: Record<string, string> }) => Promise<HttpResult>;

export const sleep = (ms: number): Promise<void> => new Promise((r) => setTimeout(r, ms));

export function jitter(min: number, max: number): number {
  return Math.round(min + Math.random() * (max - min));
}

const RETRYABLE = new Set([429, 500, 502, 503, 504]);

export function createHttp(opts: HttpOpts): HttpGet {
  const timeoutMs = opts.timeoutMs ?? 30_000;
  const maxAttempts = opts.maxAttempts ?? 3;
  const baseDelayMs = opts.baseDelayMs ?? 800;
  const [jMin, jMax] = opts.jitterMs ?? [0, 0];
  const doFetch: FetchLike = opts.fetchImpl ?? (async (url, init) => {
    const res = await fetch(url, init);
    return { status: res.status, body: await res.text() };
  });

  return async (url, init) => {
    if (jMax > 0) await sleep(jitter(jMin, jMax));
    let last: HttpResult = { status: 0, text: '', error: 'network', json: () => JSON.parse('null') };

    for (let attempt = 1; attempt <= maxAttempts; attempt++) {
      const ac = new AbortController();
      const timer = setTimeout(() => ac.abort(), timeoutMs);
      try {
        const res = await doFetch(url, {
          headers: { 'user-agent': opts.userAgent, accept: 'text/html,application/json;q=0.9,*/*;q=0.8', ...init?.headers },
          signal: ac.signal,
        });
        if (RETRYABLE.has(res.status) && attempt < maxAttempts) {
          last = { status: res.status, text: res.body, error: 'http', json: () => JSON.parse('null') };
          await sleep(baseDelayMs * 2 ** (attempt - 1) + jitter(0, 250));
          continue;
        }
        const text = res.body;
        return { status: res.status, text, error: res.status >= 400 ? 'http' : undefined, json: <T>(): T => JSON.parse(text) as T };
      } catch (err) {
        const isTimeout = (err as Error).name === 'AbortError';
        last = { status: 0, text: '', error: isTimeout ? 'timeout' : 'network', json: () => JSON.parse('null') };
        if (attempt < maxAttempts) await sleep(baseDelayMs * 2 ** (attempt - 1));
      } finally {
        clearTimeout(timer);
      }
    }
    return last;
  };
}
```

Note a mudança em relação à primeira redação: `RETRYABLE` não contém `0`. Colocar `0` dentro do conjunto e depois testar `res.status !== 200` tornava a condição impossível de ler — status `0` nunca vem do `fetch`, só do estado de erro interno. Como está, `RETRYABLE` lista apenas os códigos HTTP que valem uma nova tentativa.

import type { MonitorParams, SearchMonitor } from '@brique/core/types';

const HOST = 'https://www.olx.com.br';
const MAX_PAGES = 6;
const DIACRITICS = new RegExp('[\\u0300-\\u036f]', 'g');

const slug = (s: string): string =>
  s.toLowerCase().normalize('NFD').replace(DIACRITICS, '').replace(/\s+/g, '-').replace(/[^a-z0-9-]/g, '');

function locationPath(p: MonitorParams): string {
  if (p.city) return `/estado/${slug(p.city)}-e-regiao`;
  if (p.uf) return `/estado/${slug(p.uf)}-e-regiao`;
  return '/brasil';
}

export function buildSearchUrl(monitor: SearchMonitor, page: number): string {
  const p = monitor.params;
  const q = new URLSearchParams({ q: monitor.query });
  if (p.minCents != null) q.set('f', mergeF(q.get('f'), `price_min_${Math.round(p.minCents / 100)}`));
  if (p.maxCents != null) q.set('f', mergeF(q.get('f'), `price_max_${Math.round(p.maxCents / 100)}`));
  if (p.extraQuery) for (const [k, v] of new URLSearchParams(p.extraQuery)) q.set(k, v);
  const capped = Math.min(Math.max(page, 1), MAX_PAGES);
  return `${HOST}${locationPath(p)}?${q.toString()}&o=${capped}`;
}

function mergeF(existing: string | null, add: string): string {
  return existing ? `${existing}_${add}` : add;
}
```

A localização vive só no path, não também no query string: a OLX resolve estado/cidade pelo segmento `/estado/<slug>-e-regiao`, e um `?state=pr&city=curitiba` ao lado seria um segundo canal dizendo a mesma coisa — canal esse que a página ignora, mas que faria duas monitores diferentes gerarem URLs que parecem distintas e servem o mesmo HTML. O `slug()` tira acento porque `p.uf` pode chegar como `'São Paulo'` do painel e `'são-paulo-e-regiao'` é 404 garantido; por isso o `.replace(/\s+/g, '-')` vem antes do filtro de caracteres e não depois.

O formato de `f=price_min_N_price_max_N` e do path `/estado/<cidade>-e-regiao` é **verificado no Step 6 contra a página viva** — se divergir, este arquivo é o único lugar a corrigir, e o contrato do adapter não muda.

export interface OlxAd {
  externalId: string;
  title: string;
  priceRaw: string;
  url: string;
  city: string | null;
  uf: string | null;
  description: string;
  imageUrls: string[];
  sellerRef: string | null;
  publishedAt: string | null;
}

interface Candidate {
  id?: unknown; title?: unknown; description?: unknown; price?: unknown;
  slug?: unknown; link?: unknown; url?: unknown; location?: unknown; images?: unknown;
  ads?: unknown; store?: unknown; seller?: unknown; createdTime?: unknown;
}

const isObj = (v: unknown): v is Candidate => typeof v === 'object' && v !== null;

export function findAds(payload: unknown): Candidate[] {
  const found: Candidate[] = [];
  const seen = new Set<unknown>();
  const walk = (node: unknown): void => {
    if (!isObj(node) || seen.has(node)) return;
    seen.add(node);
    if (typeof node.id !== 'undefined' && typeof node.title === 'string' && typeof node.price !== 'undefined') {
      found.push(node);
      return;
    }
    for (const value of Object.values(node)) {
      if (Array.isArray(value)) value.forEach(walk);
      else if (isObj(value)) walk(value);
    }
  };
  walk(payload);
  return found;
}

export function parseNextData(html: string): unknown {
  const m = html.match(/<script[^>]+id="__NEXT_DATA__"[^>]*>([\s\S]*?)<\/script>/i);
  if (!m || !m[1]) return null;
  try { return JSON.parse(m[1]); } catch { return null; }
}

const firstString = (...vals: unknown[]): string | null => {
  for (const v of vals) if (typeof v === 'string' && v.trim()) return v;
  return null;
};

const numToStr = (v: unknown): string => {
  if (typeof v === 'number') return String(v);
  if (typeof v === 'string') return v;
  if (isObj(v)) return firstString((v as Candidate).value, (v as Candidate).formatted) ?? '';
  return '';
};

export function toAd(candidate: Candidate): OlxAd | null {
  const externalId = firstString(String(candidate.id ?? ''));
  const title = firstString(candidate.title);
  const priceRaw = numToStr(candidate.price);
  if (!externalId || !title) return null;

  const loc = isObj(candidate.location) ? candidate.location as { city?: { name?: unknown }; state?: { initials?: unknown; name?: unknown } } : {};
  const images = Array.isArray(candidate.images)
    ? (candidate.images as Array<{ id?: unknown; cloudKeyId?: unknown; url?: unknown }>)
        .map((i) => firstString(i.url, i.cloudKeyId ? `https://OLX_IMG_BASE/${i.cloudKeyId}` : null, i.id ? `https://OLX_IMG_BASE/${i.id}` : null))
        .filter((x): x is string => x !== null)
    : [];

  return {
    externalId,
    title,
    priceRaw,
    url: firstString(candidate.url, candidate.link, candidate.slug ? `https://www.olx.com.br/anuncio/${candidate.slug}` : null) ?? '',
    city: firstString(isObj(loc.city) ? (loc.city as { name?: unknown }).name : null),
    uf: firstString(isObj(loc.state) ? (loc.state as { initials?: unknown }).initials : null),
    description: firstString(candidate.description) ?? '',
    imageUrls: images.slice(0, 12),
    sellerRef: firstString(isObj(candidate.store) ? (candidate.store as { name?: unknown }).name : null,
      isObj(candidate.seller) ? (candidate.seller as { name?: unknown }).name : null),
    publishedAt: firstString(candidate.createdTime),
  };
}

const CARD_RE = /<a[^>]+href="(\/anuncio\/[^"]+)"[^>]*>([\s\S]*?)<\/a>/gi;
const PRICE_IN_CARD_RE = /R\$\s*[\d.,]+/;

export function parseCardHtml(html: string): OlxAd[] {
  const out: OlxAd[] = [];
  for (const [, href, inner] of html.matchAll(CARD_RE)) {
    const text = inner.replace(/<[^>]+>/g, ' ').replace(/\s+/g, ' ').trim();
    const priceMatch = text.match(PRICE_IN_CARD_RE);
    if (!priceMatch) continue;
    const title = text.slice(0, text.indexOf(priceMatch[0])).trim() || 'sem titulo';
    out.push({
      externalId: href.split('/').pop()!.replace(/\?.*$/, ''),
      title, priceRaw: priceMatch[0], url: `https://www.olx.com.br${href}`,
      city: null, uf: null, description: '', imageUrls: [], sellerRef: null, publishedAt: null,
    });
  }
  return out;
}

import { parsePriceBRL } from '@brique/core/money';
import type { ListingInput, RawListing, SearchMonitor } from '@brique/core/types';
import type { HttpGet } from '../http';
import { sleep, jitter } from '../http';
import { parseNextData, findAds, toAd, parseCardHtml, type OlxAd } from './extract';
import { buildSearchUrl } from './url';

const HOST = 'https://www.olx.com.br';

export const isOlxAd = (x: OlxAd | null): x is OlxAd => x !== null;

export interface OlxAdapterDeps { http: HttpGet }

export function createOlxAdapter(deps: OlxAdapterDeps) {
  const extract = (text: string): OlxAd[] => {
    const blob = parseNextData(text);
    if (blob) {
      const fromBlob = findAds(blob).map(toAd).filter(isOlxAd);
      if (fromBlob.length > 0) return fromBlob;
    }
    return parseCardHtml(text);
  };

  return {
    id: 'olx' as const,
    parserVersion: 'olx-1',

    async health() {
      const res = await deps.http(`${HOST}/brasil?q=teste`);
      if (res.status === 200 && res.text.length > 500) return { ok: true };
      return { ok: false, reason: `http ${res.status} / ${res.error ?? 'corpo curto'}` };
    },

    async search(monitor: SearchMonitor, _since: Date) {
      const pages = Math.min(monitor.params.pages ?? 3, 6);
      const out: RawListing[] = [];
      for (let page = 1; page <= pages; page++) {
        const res = await deps.http(buildSearchUrl(monitor, page));
        if (res.error === 'http' && (res.status === 403 || res.status === 429)) break;
        if (res.status !== 200) break;
        const ads = extract(res.text);
        if (ads.length === 0) break;
        for (const ad of ads) {
          out.push({ source: 'olx', externalId: ad.externalId, url: ad.url, fetchedAt: new Date(), payload: ad });
        }
        await sleep(jitter(1500, 4000));
      }
      return out;
    },

    async fetchOne(externalId: string) {
      const res = await deps.http(`${HOST}/anuncio/${externalId}`);
      const ads = extract(res.text);
      const ad = ads.find((a) => a.externalId === externalId) ?? ads[0];
      if (!ad) throw new Error(`olx: anuncio ${externalId} nao parseado (status ${res.status})`);
      return { source: 'olx' as const, externalId: ad.externalId, url: ad.url, fetchedAt: new Date(), payload: ad };
    },

    toListingInput(raw: RawListing): ListingInput | { rejected: true; reason: string; rawTitle: string } {
      const ad = raw.payload as OlxAd;
      const price = parsePriceBRL(ad.priceRaw);
      if (!price.ok) return { rejected: true, reason: price.reason, rawTitle: ad.title };
      return {
        source: 'olx',
        externalId: ad.externalId,
        url: ad.url || raw.url,
        title: ad.title,
        description: ad.description ?? '',
        askingCents: price.cents,
        askingRaw: ad.priceRaw,
        city: ad.city,
        uf: ad.uf,
        imageUrls: ad.imageUrls ?? [],
        sellerRef: ad.sellerRef,
        publishedAt: ad.publishedAt ? new Date(ad.publishedAt) : null,
      };
    },
  };
}

export type OlxAdapter = ReturnType<typeof createOlxAdapter>;

```ts
import type { ListingInput, RawListing, SearchMonitor } from '@brique/core/types';
import type { HttpGet } from '../http';
import { sleep } from '../http';
import { meliHeaders, searchUrl } from './auth';

export interface MeliItem {
  id: string; title: string; price: number; available_quantity?: number; sold_quantity?: number;
  condition?: string; catalog_product_id?: string | null; permalink?: string; thumbnail?: string;
  address?: { state?: { name?: string; id?: string } }; seller_id?: number;
}

const LIMIT = 50;
const MAX_PAGES = 4;

const toCents = (price: number): number => Math.round(price * 100);

export function createMeliAdapter(deps: { http: HttpGet; token: string | null; unit: string }) {
  const available = deps.token !== null;

  return {
    id: 'meli' as const,
    parserVersion: 'meli-1',
    available,

    async health() {
      if (!available) return { ok: false, reason: 'sem MELI_ACCESS_TOKEN; fonte desabilitada' };
      const res = await deps.http(searchUrl(deps.unit, 'iphone', 1, 0), { headers: meliHeaders(deps.token) });
      if (res.status === 200) return { ok: true };
      return { ok: false, reason: `http ${res.status} / ${res.error ?? 'ok?'}` };
    },

    async search(monitor: SearchMonitor, _since: Date): Promise<RawListing[]> {
      if (!available) return [];
      const pages = Math.min(monitor.params.pages ?? 2, MAX_PAGES);
      const out: RawListing[] = [];
      for (let page = 0; page < pages; page++) {
        const res = await deps.http(
          searchUrl(deps.unit, monitor.query, LIMIT, page * LIMIT),
          { headers: meliHeaders(deps.token) },
        );
        if (res.status !== 200) break;
        const body = res.json<{ results?: MeliItem[]; paging?: { total: number } }>();
        const items = body.results ?? [];
        if (items.length === 0) break;
        for (const it of items) {
          out.push({ source: 'meli', externalId: it.id, url: it.permalink ?? `https://www.mercadolivre.com.br/p/${it.id}`, fetchedAt: new Date(), payload: it });
        }
        await sleep(1000);
      }
      return out;
    },

    async fetchOne(externalId: string): Promise<RawListing> {
      if (!available) throw new Error('meli: token ausente');
      const res = await deps.http(`https://api.mercadolibre.com/items/${externalId}`, { headers: meliHeaders(deps.token) });
      if (res.status !== 200) throw new Error(`meli: item ${externalId} status ${res.status}`);
      const item = res.json<MeliItem>();
      return { source: 'meli', externalId: item.id, url: item.permalink ?? '', fetchedAt: new Date(), payload: item };
    },

    toListingInput(raw: RawListing): ListingInput | { rejected: true; reason: string; rawTitle: string } {
      const it = raw.payload as MeliItem;
      if (typeof it.price !== 'number' || !Number.isFinite(it.price)) {
        return { rejected: true, reason: 'not-a-price', rawTitle: it.title ?? raw.externalId };
      }
      const cents = toCents(it.price);
      if (cents === 0) return { rejected: true, reason: 'zero', rawTitle: it.title ?? raw.externalId };
      return {
        source: 'meli',
        externalId: it.id,
        url: raw.url,
        title: it.title,
        description: [it.condition ? `condicao:${it.condition}` : null, `sold_quantity:${it.sold_quantity ?? '?'}`].filter(Boolean).join(' '),
        askingCents: cents,
        askingRaw: String(it.price),
        city: null,
        uf: null,
        imageUrls: it.thumbnail ? [it.thumbnail] : [],
        sellerRef: it.seller_id ? String(it.seller_id) : null,
        publishedAt: null,
      };
    },
  };
}

export type MeliAdapter = ReturnType<typeof createMeliAdapter>;
```

```ts
const sortedCopy = (values: number[]): number[] => [...values].sort((a, b) => a - b);

export function medianCents(values: number[]): number | null {
  if (values.length === 0) return null;
  const s = sortedCopy(values);
  const mid = Math.floor(s.length / 2);
  return s.length % 2 === 0 ? Math.round((s[mid - 1]! + s[mid]!) / 2) : s[mid]!;
}

export function quantile(values: number[], q: number): number | null {
  if (values.length === 0) return null;
  const s = sortedCopy(values);
  const pos = (s.length - 1) * q;
  const base = Math.floor(pos);
  const rest = pos - base;
  const lower = s[base]!;
  const upper = s[base + 1] ?? lower;
  return Math.round(lower + rest * (upper - lower));
}

export function keepFlags(values: number[], ratio = 0.1): boolean[] {
  const n = values.length;
  if (n === 0) return [];

  if (n < 7) {
    const med = medianCents(values)!;
    const flags = values.map((v) => v <= med * 3 && v >= med / 3);
    return flags.some(Boolean) ? flags : values.map(() => true);
  }

  const cut = Math.floor(n * ratio);
  const order = values.map((v, i) => ({ v, i })).sort((a, b) => a.v - b.v).map((x) => x.i);
  const flags: boolean[] = new Array(n).fill(true);
  for (let k = 0; k < cut; k++) {
    flags[order[k]!] = false;
    flags[order[n - 1 - k]!] = false;
  }
  return flags;
}

export function trimOutliers(values: number[], ratio = 0.1): { kept: number[]; trimmed: number[] } {
  const flags = keepFlags(values, ratio);
  const kept: number[] = [];
  const trimmed: number[] = [];
  values.forEach((v, i) => (flags[i] ? kept : trimmed).push(v));
  return { kept: sortedCopy(kept), trimmed: sortedCopy(trimmed) };
}
```

`keepFlags` devolve um booleano por posição, não dois arrays de valores, porque `valueFingerprint` (Step 7) precisa saber **qual anúncio** ficou de fora — não só quais preços ficaram de fora. Dois anúncios de R$ 12.000,00 um ao lado do outro não se distinguem por valor; distinguem por índice. `trimOutliers` é a mesma regra vista por valor, e existe para os testes de mediana continuarem lendo como aritmética.

- com `n < 7`, a mediana da amostra é pequena demais para um corte por percentil significar alguma coisa: aí a guarda é a regra absoluta (fora de `[med/3, med*3]`), e se ela não sobrasse nada a amostra inteira é mantida, porque uma mediana de uma amostra que se autodivorou é pior que a amostra crua.
- com `n >= 7`, `cut = floor(n * ratio)` corta `cut` do lado mais baixo e `cut` do mais alto. Com `n = 10` e `ratio = 0.1`, `cut = 1`: sai o menor e o maior. Com `n = 7`, `floor(0.7) = 0`: não sai nada, e isso é o comportamento correto — percentil 10% de 7 itens é um pedido de arredondamento, não um recorte estatístico.

import { and, eq, gte } from 'drizzle-orm';
import type { Db } from '../db/client';
import { listings } from '../db/schema';
import type { Category, Settings, Valuation } from '../types';

export function liquidityFor(
  db: Db,
  fingerprintId: number,
  category: Category,
  settings: Settings,
  now: Date,
): { days: number; source: Valuation['liquiditySource'] } {
  const windowStart = new Date(now.getTime() - 180 * 86_400_000);
  const rows = db.select({
      first: listings.firstSeenAt,
      last: listings.lastSeenAt,
    })
    .from(listings)
    .where(and(
      eq(listings.fingerprintId, fingerprintId),
      eq(listings.status, 'gone'),
      gte(listings.lastSeenAt, windowStart),
    ))
    .all();

  if (rows.length >= 5) {
    const spans = rows.map((r) => Math.max(1, Math.round((r.last.getTime() - r.first.getTime()) / 86_400_000)));
    const avg = Math.round(spans.reduce((a, b) => a + b, 0) / spans.length);
    return { days: Math.min(Math.max(avg, 1), 120), source: 'market' };
  }

  return { days: settings.liquidityDefaults[category], source: 'category-default' };
}

```ts
import type { Db } from '../db/client';
import type { ComparablesProvider } from './comparables';
import type { Category, Confidence, Settings, Valuation } from '../types';
import { keepFlags, medianCents, quantile } from './median';
import { liquidityFor } from './liquidity';

export interface ValueOpts {
  settings: Settings;
  now: Date;
  provider: ComparablesProvider;
  category: Category;
  windowDays?: number;
  excludeListingId?: number;
}

export interface ValueResult {
  valuation: Valuation;
  comparables: { listingId: number; askingCents: number; role: 'kept' | 'trimmed' }[];
  sampleGate: 'ok' | 'insufficient';
}

export function confidenceFor(sampleSize: number, variantAgnostic: boolean): Confidence | null {
  const capped: Confidence | null =
    sampleSize >= 8 ? 'high' : sampleSize >= 5 ? 'med' : sampleSize >= 3 ? 'low' : null;
  if (!capped) return null;
  return variantAgnostic && capped === 'high' ? 'med' : capped;
}

export function valueFingerprint(db: Db, fingerprintId: number, opts: ValueOpts): ValueResult {
  const windowDays = opts.windowDays ?? 90;
  const base = { fingerprintId, windowDays, now: opts.now, excludeListingId: opts.excludeListingId };
  const exact = opts.provider.collect(db, { ...base, variantAgnostic: false });
  const useAgnostic = exact.length < 3;
  const raw = useAgnostic ? opts.provider.collect(db, { ...base, variantAgnostic: true }) : exact;

  const values = raw.map((c) => c.askingCents);
  const flags = keepFlags(values, 0.1);
  const kept = values.filter((_, i) => flags[i]);
  const comparables = raw.map((c, i) => ({ listingId: c.listingId, askingCents: c.askingCents, role: flags[i] ? 'kept' as const : 'trimmed' as const }));
  const median = medianCents(kept);

  const delta = opts.settings.delta;
  const fairGross = median === null ? null : Math.round(median * delta);
  const liq = liquidityFor(db, fingerprintId, opts.category, opts.settings, opts.now);
  const confidence = confidenceFor(kept.length, useAgnostic) ?? 'low';

  return {
    valuation: {
      fingerprintId,
      sampleSize: kept.length,
      medianCents: median,
      p25Cents: quantile(kept, 0.25),
      p75Cents: quantile(kept, 0.75),
      fairGrossCents: fairGross,
      delta,
      liquidityDays: liq.days,
      liquiditySource: liq.source,
      confidence,
      variantAgnostic: useAgnostic,
      computedAt: opts.now,
    },
    comparables,
    sampleGate: kept.length < 3 ? 'insufficient' : 'ok',
  };
}
```

O `role` sai de `flags[i]`, na posição do array recebido: nada de `Set` de preços nem contador de "quantos já vi". Um `new Set(kept)` colapsa empates — dois anúncios a R$ 12.000,00 viram um elemento — e aí um item aparado pode ser marcado como mantido só porque algum outro preço igual sobreviveu. O painel mostraria uma valuation cuja lista de comparáveis não bate com a mediana que ela anuncia, e essa divergência é exatamente o tipo de erro que se descobre quando já se comprou o item.

Regra de decisão codificada aqui: amostra exata com `n < 3` tenta o fallback `variant-agnostic` (mesma marca/modelo, ignorando capacidade/lock) e tem a confiança limitada a `med` — nunca `high`. Uma mediana que mistura 64GB com 256GB não merece te mandar um push de "oportunidade alta".

const GRADE_REPAIR_FACTOR: Record<Grade, number> = { A: 0, B: 0.5, C: 1, D: 3 };

export function costsIn(askingCents: Cents, category: Category, grade: Grade, s: Settings): Cents {
  return askingCents
    + s.shippingInDefaultCents[category]
    + Math.round(s.repairDefaultCents[category] * GRADE_REPAIR_FACTOR[grade]);
}

export function netRealizable(fairGrossCents: Cents | null, outPlatform: string, s: Settings, category: Category): Cents | null {
  if (fairGrossCents === null) return null;
  const fee = s.platformFeePct[outPlatform] ?? 0;
  const gross = Math.round(fairGrossCents * (1 - fee - s.taxPct)) - s.shippingOutDefaultCents[category];
  return gross > 0 ? gross : null;
}

const CONFIDENCE_FACTOR = { low: 0.3, med: 0.7, high: 1.0 } as const;

const clamp01 = (v: number): number => (v <= 0 ? 0 : v >= 1 ? 1 : v);

export function scoreOpportunity(args: {
  askingCents: number;
  valuation: Valuation;
  category: Category;
  grade: Grade;
  outPlatform: string;
  seenAt: Date;
  now: Date;
  settings: Settings;
}): OpportunityMath {
  const s = args.settings;
  const v = args.valuation;
  const costs = costsIn(args.askingCents, args.category, args.grade, s);
  const net = netRealizable(v.fairGrossCents, args.outPlatform, s, args.category);
  const margin = net === null ? null : net - costs;
  const marginPct = margin === null || costs === 0 ? null : margin / costs;
  const liquidityDays = Math.max(v.liquidityDays, 1);
  const expectedPerDay = margin === null || margin <= 0 ? null : Math.round(margin / liquidityDays);

  const profitFactor = clamp01((expectedPerDay ?? 0) / s.metaPerDayCents);
  const liquidityFactor = clamp01(s.metaDays / liquidityDays);
  const confidenceFactor = CONFIDENCE_FACTOR[v.confidence];
  const ageDays = Math.max(0, (args.now.getTime() - args.seenAt.getTime()) / 86_400_000);
  const freshnessFactor = Math.exp(-ageDays / 3);

  const score = v.sampleSize === 0 || margin === null
    ? 0
    : clamp01(
        s.weights.profit * profitFactor
        + s.weights.liquidity * liquidityFactor
        + s.weights.confidence * confidenceFactor
        + s.weights.freshness * freshnessFactor,
      );

  return {
    askingCents: args.askingCents,
    fairGrossCents: v.fairGrossCents,
    netRealizableCents: net,
    costsInCents: costs,
    marginCents: margin,
    marginPct,
    expectedPerDayCents: expectedPerDay,
    liquidityDays,
    score,
    breakdown: { profitFactor, liquidityFactor, confidenceFactor, freshnessFactor },
  };
}

export { costsIn, netRealizable };
```

import type { Confidence, GateReason, OpportunityMath, Settings } from '../types';

export interface GateArgs {
  math: OpportunityMath;
  sampleGate: 'ok' | 'insufficient';
  hasFingerprint: boolean;
  settings: Settings;
  confidence?: Confidence;
}

export function gate(args: GateArgs): { passed: boolean; reason: GateReason } {
  if (!args.hasFingerprint) return { passed: false, reason: 'sem-fingerprint' };
  if (args.sampleGate === 'insufficient') return { passed: false, reason: 'amostra-insuficiente' };

  const pct = args.math.marginPct;
  const cents = args.math.marginCents;
  if (pct === null || cents === null) return { passed: false, reason: 'abaixo-do-floor' };

  const pctFloor = args.confidence === 'low' ? args.settings.floorMarginPct * 2 : args.settings.floorMarginPct;
  if (pct >= pctFloor && cents >= args.settings.floorMarginCents) return { passed: true, reason: 'ok' };
  return { passed: false, reason: 'abaixo-do-floor' };
}
```

Ordem das checagens é contrato, não estilo: `sem-fingerprint` vem antes de qualquer número porque um item sem fingerprint não tem margem calculada — devolver `abaixo-do-floor` faria a fila dizer "margem baixa" onde a verdade é "não sei o que é". `amostra-insuficiente` vem em seguida pela mesma razão: com dois comparáveis a margem existe, o que não existe é base para confiar nela. E `marginPct === null` é tratado antes do floor porque `null >= 0.35` é `false` em JS e o item seria bloqueado com o motivo certo por acidente. Os dois floors são lidos de `args.settings`, nunca de constante literal, porque a spec §6.2 promete que o operador ajusta o floor sem mexer em código; o teste `lê os floors das settings recebidas` é o que impede a regressão.

```ts
import type { Cents } from './types';
import { jaccard, shingles } from './text';

export function samePriceWindow(a: Cents, b: Cents, tolerancePct = 0.05): boolean {
  if (a <= 0 || b <= 0) return false;
  return Math.abs(a - b) / Math.max(a, b) <= tolerancePct;
}

export function findDupe(
  candidates: { listingId: number; title: string; askingCents: Cents }[],
  target: { title: string; askingCents: Cents },
): number | null {
  const targetSet = shingles(target.title);
  if (targetSet.size === 0) return null;
  let bestId: number | null = null;
  let bestScore = 0.55;
  for (const c of candidates) {
    if (!samePriceWindow(c.askingCents, target.askingCents)) continue;
    const score = jaccard(targetSet, shingles(c.title));
    if (score > bestScore) { bestScore = score; bestId = c.listingId; }
  }
  return bestId;
}
```

`bestScore` começa em 0.55 e não em 0: o limiar da spec é uma comparação estrita (`> 0.55`), e inicializar o melhor com o próprio limiar dispensa um `if (score < 0.55) continue` que diria a mesma coisa duas vezes. `samePriceWindow` divide por `Math.max(a, b)` em vez da média para que a tolerância seja assimétrica a favor do barato — um anúncio de R$ 95.000,00 e um de R$ 100.000,00 estão a 5% um do outro nos dois sentidos, e R$ 100.000,00 contra R$ 106.000,00 já não estão.

  db: Db,
  source: SourceId,

import type { ComparablesProvider } from './valuation/comparables';
import type { AiTriagePort } from './ai-port';
import type { Db } from './db/client';
import type { SearchMonitor, Settings } from './types';
import { isRejected, type SourceAdapter } from './adapter-contract';

export interface PipelineDeps {
  db: Db;
  settings: Settings;
  adapter: SourceAdapter;
  ai: AiTriagePort;
  comparables: ComparablesProvider;
  now: () => Date;
  deadlineMs?: number;
  outPlatform?: string;

export async function runMonitor(deps: PipelineDeps, monitor: SearchMonitor): Promise<RunSummary> {
  const { db, settings } = deps;
  const startedAt = deps.now();
  const runId = startRun(db, monitor.id, startedAt);
  const deadline = deps.deadlineMs ?? 600_000;

  const summary: RunSummary = { outcome: 'ok', fetched: 0, created: 0, repriced: 0, unchanged: 0, rejected: {}, unmatched: 0, aiCalls: 0 };
  let timedOut = false;

  try {
    const raws = await deps.adapter.search(monitor, monitor.lastRunAt ?? new Date(startedAt.getTime() - 86_400_000));
    summary.fetched = raws.length;
    const seenIds: string[] = [];

    for (const raw of raws) {
      if (deps.now().getTime() - startedAt.getTime() > deadline) { summary.outcome = 'partial'; timedOut = true; break; }
      seenIds.push(raw.externalId);

      const parsed = deps.adapter.toListingInput(raw);
      if (isRejected(parsed)) {
        summary.rejected[parsed.reason] = (summary.rejected[parsed.reason] ?? 0) + 1;
        continue;
      }
      const input = parsed;

      const product = extractProduct(input.title, input.description);
      if (!product.matched) summary.unmatched++;

      const fp = product.matched ? getOrCreateFingerprint(db, product) : null;
      const upsert = upsertFromSource(db, input, {
        parserVersion: deps.adapter.parserVersion,
        monitorId: monitor.id,
        fingerprintId: fp?.id ?? null,
        grade: product.matched ? product.grade : null,
        seenAt: deps.now(),
      });

      if (upsert.transition === 'new') summary.created++;
      else if (upsert.transition === 'repriced') summary.repriced++;
      else { summary.unchanged++; continue; }

      const dupeCands = findRecentCrossSource(db, input.source, new Date(deps.now().getTime() - 72 * 3_600_000), listFingerprintIdsByCategory(db, product.category));
      const dupeId = product.matched ? findDupe(dupeCands, { title: input.title, askingCents: input.askingCents }) : null;
      if (dupeId && dupeId !== upsert.id) {
        attachDupe(db, upsert.id, dupeId);
        setStatus(db, upsert.id, 'ignored');
        continue;
      }

      if (!fp) continue;

      const value = valueFingerprint(db, fp.id, {
        settings, now: deps.now(), provider: deps.comparables, category: product.category,
        excludeListingId: upsert.id,
      });
      const { id: valuationId } = insertValuation(db, fp.id, value.valuation, value.comparables);

      const math = scoreOpportunity({
        askingCents: input.askingCents, valuation: value.valuation, category: product.category,
        grade: product.grade, outPlatform: deps.outPlatform ?? 'meli', seenAt: deps.now(), now: deps.now(), settings,
      });

      const g = gate({ math, sampleGate: value.sampleGate, hasFingerprint: true, settings, confidence: value.valuation.confidence });
      if (!g.passed) {
        insertOpportunity(db, upsert.id, math, { valuationId, gatePassed: false, gateReason: g.reason, createdAt: deps.now() });
        continue;
      }

      insertOpportunity(db, upsert.id, math, { valuationId, gatePassed: true, gateReason: 'ok', createdAt: deps.now() });
      setStatus(db, upsert.id, 'shortlisted');
    }

    if (raws.length > 0 && !timedOut) markGone(db, deps.adapter.id, seenIds, deps.now());
    touchRun(db, monitor.id, deps.now(), summary.created + summary.repriced);
  } catch (err) {
    summary.outcome = 'failed';
    summary.error = (err as Error).message;
  }

  finishRun(db, runId, deps.now(), summary);
  return summary;
}
```

Cinco decisões embutidas que um revisitar contestaria, cada uma com o defeito que evita:

- **`seenIds.push(raw.externalId)` vem antes do `isRejected`.** O `raw.externalId` é observado pelo feed; o preço é que não foi lido. Se a rejeição pular o `push`, o `markGone` do final da passada transforma “não consegui ler o preço hoje” em “este anúncio saiu do ar”, e o item some da sua frente para sempre — no pior caso, o anúncio com o melhor preço da semana é justamente o que tem um preço formatado de um jeito que o parser ainda não cobre.
- **`markGone` só roda com `raws.length > 0 && !timedOut`.** Rede: uma passada que devolve zero anúncios pode ser página vazia ou pode ser bloqueio; nas duas, marcar a cidade inteira como expirada é apagar estado com base em uma resposta ruim. Tempo: se o `deadline` cortou o laço no meio, os anúncios que não foram visitados continuam vivos no feed, mas não entraram em `seenIds`, e o `markGone` os declararia expirados por estouro de prazo. O `summary.outcome = 'partial'` fica registrado no próprio `break` — o que a flag `timedOut` acrescenta é que uma passada parcial não tem autoridade para declarar nada expirado.
- **`valuationId` é o id devolvido por `insertValuation`, nos dois ramos do gate.** Passar `null` no ramo reprovado deixa o `leftJoin` de `listShortlistedRanked` sem âncora e o painel (M6) não consegue mostrar “por que este item foi bloqueado”: a amostra, a mediana e a confiança que explicam o `abaixo-do-floor` moram na valuation. Gravar a valuation antes do gate é o que permite isso, e custa uma query local, não cota de IA.
- **Nenhum ramo chama `deps.ai`.** Em M0–M4 o gate determinístico já shortlistiza; a IA entra em M5 como **veto e rebaixamento**, nunca como promoção, e por isso o `ai` continua em `PipelineDeps` com `nullAiPort()` injetado — a assinatura já está pronta e o teste `expect(ai.calls).toBe(0)` trava que nada aqui puxe a chamada antes da hora. O orçamento do pool gratuito é o recurso mais escasso do sistema; gastar 40 chamadas por passada em M4, quando não há nenhum uso para elas, é o jeito mais rápido de ficar sem cota no dia em que a IA ligar.

- **O escopo de deduplicação é lido por item, não injetado.** `fingerprintIds` já foi um campo de `PipelineDeps`, e era um defeito: o worker o lia na subida do processo, quando a tabela `fingerprint` está vazia num banco recém-criado. O resultado era um `findRecentCrossSource` que devolve `[]` para sempre, ou seja, o dedupe cross-source simplesmente nunca rodava enquanto o processo não fosse reiniciado — e como o `[]` é um retorno legítimo, nada quebrava. `listFingerprintIdsByCategory(db, product.category)` custa um `SELECT` de inteiros por item novo, no SQLite local do worker, e devolve também o fingerprint criado três itens atrás na mesma passada.

`isRejected` é *type guard* (Task 10), então `const input = parsed;` já chega tipado como `ListingInput`; o `as ListingInput` que existia aqui era um `cast` que sobreviveria a uma mudança de contrato sem avisar.

```ts
import { listDue } from './db/repo/monitors';
import { runMonitor, type PipelineDeps } from './pipeline';
import type { SourceAdapter } from './adapter-contract';
import type { SourceId } from './types';
import type { RunSummary } from './db/repo/runs';

export type SchedulerDeps = Omit<PipelineDeps, 'adapter'> & {
  adapters: Partial<Record<SourceId, SourceAdapter>>;
};

export async function runPending(deps: SchedulerDeps): Promise<RunSummary[]> {
  const due = listDue(deps.db, deps.now());
  const out: RunSummary[] = [];
  for (const monitor of due) {
    const adapter = deps.adapters[monitor.source];
    if (!adapter) continue;
    out.push(await runMonitor({ ...deps, adapter }, monitor));
  }
  return out;
}

export function startScheduler(
  deps: SchedulerDeps,
  tickMs = 30_000,
  onPass?: (summaries: RunSummary[]) => void,
): { stop: () => void } {
  let busy = false;
  let stopped = false;
  const loop = async () => {
    if (busy || stopped) return;
    busy = true;
    try {
      const summaries = await runPending(deps);
      if (summaries.length > 0) onPass?.(summaries);
    } finally { busy = false; }
  };
  void loop();
  const timer = setInterval(() => void loop(), tickMs);
  return { stop: () => { stopped = true; clearInterval(timer); } };
}
```

Fila serial por construção: um `for await` sobre os monitores vencidos, sem `Promise.all`. É a decisão da spec §10 (concorrência aqui só aumenta risco de bloqueio de IP) e o `busy` impede que uma passada longa se sobreponha ao tick seguinte.

O `adapters` é um registro `Partial<Record<SourceId, SourceAdapter>>` e não um `adapter` único por um motivo funcional: monitores `source: 'meli'` e `source: 'olx'` convivem na mesma tabela, e rotear pelo `monitor.source` é o que faz o plugue da spec §4 ser real — adicionar Enjoei em M8 é registrar mais uma chave, não mexer no laço. O `if (!adapter) continue` descarta com silêncio consciente o monitor cuja fonte não foi configurada (MELI sem `MELI_ACCESS_TOKEN`); o `run` dessa passada simplesmente não existe, em vez de uma linha `failed` que poluiria a saúde da fonte. E `onPass` existe porque o `printShortlist` precisa de um gancho para rodar **depois** da passada, quando o banco já tem as oportunidades — sem ele, o worker imprimiria o ranking de antes.

Quatro pontos que não são cosméticos:

- `process.loadEnvFile()` no `try` é o único carregador de `.env` do projeto, e não é um `dotenv` a mais: Node 20.12+ já lê o arquivo, e o `catch` cobre o caso em que o processo nasce num systemd com `EnvironmentFile=` e sem `.env` no disco. Uma variável faltante que importa continua sendo erro de configuração, e é o `loadConfig()` (Task 2) que estoura nomeando a variável — aqui não se silencia nada além da ausência do arquivo.
- `meli` só entra no registro quando `available`. Registrar um adaptador sem token significaria escalonar monitores `source: 'meli'` contra uma fonte que responde `{ ok: false, reason: 'sem MELI_ACCESS_TOKEN' }` em toda passada e encher a tabela `run` de falhas que não são incidente de rede, são configuração conhecida no boot. O `if (!adapter) continue` do scheduler já cobre o monitor órfão com silêncio; isto aqui é o que faz ele quase nunca acontecer.
- O `if (avaliados === 0) return` na saída de terminal é o que separa *alerta* de *tatibitate*. Sem ele, o worker imprimiria o mesmo top-10 velho a cada minuto, e depois de três dias você para de ler — o que é exatamente como um sistema de alertas morre. A tabela só aparece quando a passada criou ou reprificou alguma coisa.
- `settings` é lido uma vez, no boot, e viaja dentro de `deps`. Mudar `floorMarginPct` exige reiniciar o worker; é aceitável em M0–M4 porque quem edita settings hoje é você, por SQL, e o painel (M6) vai gravar settings e reiniciar o serviço como parte do mesmo fluxo. Reconsultar a tabela `settings` por item avaliado seria a alternativa "mágica" e custaria uma query por anúncio para ganhar um atraso que ninguém pediu.

Os imports acima resolvem pelo mapa `exports` de cada pacote (`@brique/core/*` na Task 1, `@brique/scrapers/*` na Task 11), não pelos `paths` do tsconfig. Se um submódulo não resolver, o conserto é acrescentar a chave no `exports` do pacote de origem — nunca reescrever o import como `../../core/src/db/client`, porque isso atravessa a fronteira de pacote que a regra de dependência da spec §3 existe para proteger.

import { upsertFromSource } from '@brique/core/db/repo/listings';
import { extractProduct } from '@brique/core/product';
import { getOrCreateFingerprint } from '@brique/core/db/repo/fingerprints';
import { DAY1 } from '../tests/feed/day1';

const cfg = loadConfig();
const { db } = openDb(cfg.sqlitePath);
migrateDb(db);
seedSettings(db, DEFAULT_SETTINGS);

let seeded = 0;
for (const input of DAY1) {
  const p = extractProduct(input.title, input.description);
  const fp = p.matched ? getOrCreateFingerprint(db, p) : null;
  upsertFromSource(db, input, { parserVersion: 'seed-demo', fingerprintId: fp?.id ?? null, grade: p.matched ? p.grade : null, seenAt: new Date('2026-10-01T12:00:00Z') });
  seeded++;
}

const existentes = new Set(db.select({ label: searchMonitors.label }).from(searchMonitors).all().map((r) => r.label));
const novos = [
  { label: 'iPhone 12 PR', source: 'olx' as const, query: 'iphone 12', category: 'celular' as const, params: { uf: 'PR', maxCents: 400_000 }, intervalMinutes: 30 },
  { label: 'Galaxy A54 SP', source: 'olx' as const, query: 'galaxy a54', category: 'celular' as const, params: { uf: 'SP' }, intervalMinutes: 45 },
  { label: 'Caloi Elite', source: 'meli' as const, query: 'caloi elite 29', category: 'bicicleta' as const, params: {}, intervalMinutes: 60 },
].filter((m) => !existentes.has(m.label));
for (const m of novos) createMonitor(db, m);

console.log(`seed ok: ${seeded} listings, ${novos.length} monitores novos. rode: pnpm worker`);
```

O seed usa o **mesmo** `cfg.sqlitePath` do worker, e não um `./data/demo.db` à parte: se cada um apontar para um arquivo, o `pnpm seed:demo && pnpm worker` do Step 4 imprime fila vazia e a primeira conclusão é que o pipeline está quebrado. O filtro por `label` existe porque o `seed:demo` é o tipo de comando que se roda duas vezes; sem ele, cada execução duplica os três monitores e o worker passa a bater na mesma página do OLX seis vezes por ciclo — o problema de volume educado da spec §10 começando pelo próprio seed.

# Brique

## Como ler a saída

`R$/dia` é margem estimada dividida pela liquidez estimada — é o número que ordena a fila.

    packages/scrapers  um SourceAdapter por fonte; único lugar que conhece cada site
